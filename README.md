# DVScreator

Görüntü kalitesini koruyarak WhatsApp sticker'ı oluşturan, açık kaynaklı Android uygulaması.

- 🎯 **Kalite önce:** önce kayıpsız WebP denenir; 100 KB'a sığmazsa sığan en yüksek kalite otomatik bulunur.
- 🔒 **Gizlilik:** internet izni yok, hiçbir veri toplanmaz; her şey cihazda.
- 🆓 **Özgür yazılım:** GPL-3.0, kapalı kaynak bağımlılık yok.

> Proje erken geliştirme aşamasında. Plan ve yol haritası: [agents/](agents/README.md)

## Derleme

Gereksinimler: Android Studio, Android SDK, **NDK** ve **CMake** (SDK Manager → SDK Tools).

```bash
git clone --recurse-submodules <repo-adresi>
```

Projeyi Android Studio ile açıp çalıştırın.
